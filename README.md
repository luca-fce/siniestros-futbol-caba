# siniestros-futbol-caba
Se realiza para el trabajo practico de la materia [laboratorio de métodos cuantitativos aplicado a la gestión](https://github.com/Datso653/Laboratorio-de-metodos-Cuantitativos-Aplicados-a-la-gestion) un análisis de datos en grupo con el objetivo de responder a la siguiente pregunta:

*¿Se registra un aumento significativo de siniestros viales en la ciudad de Buenos Aires durante las 12 horas posteriores a la derrota de los equipos más populares de fútbol?*

### El trabajo incluye:
- Análisis realizado en Python
- Informe Académico
- Presentación

Se consideran para este trabajo todos los partidos oficiales de la selección Argentina, River Plate y Boca Juniors desde el año 2021 hasta el 2025 inclusive, junto con todos los siniestros viales registrados en la base de datos del gobierno de Buenos Aires en los mismos años.
